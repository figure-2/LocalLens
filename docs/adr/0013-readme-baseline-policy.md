# ADR 0013: README baseline policy

## 결정

공개 README는 LocalLens의 현재 기능과 실제 실행 경로를 기준으로 작성한다. 이전 버전의 구조를 참고할 수 있지만, 특정 로컬 경로·이전 저장소명·개인 또는 팀 식별자는 문서에 포함하지 않는다.

## 공개 README 원칙

- 로컬 텍스트·이미지·PDF 검색이라는 제품 목적을 명확히 설명한다.
- 실제 구현된 PostgreSQL, Qdrant, hybrid retrieval, API·UI 경로만 기술한다.
- 검증된 smoke·fixture 결과와 운영 환경 성능을 구분한다.
- AX 확장 기능은 현재 저장소에서 확인되는 범위만 기술한다.

## 금지할 표현

- 특정 이전 프로젝트명이나 원본 폴더 경로
- 이전 Git 저장소를 기준으로 작성했다는 표현
- 동일 조건 측정이 없는 정확도·성능 우위 주장
